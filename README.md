# Night City Interactive Map

An interactive SVG map of Night City by HillNSage.

Drag to pan, scroll to zoom, and use the toggles to show or hide logos and street names. Hover over a logo to see its name. The map renders vector paths directly at every zoom level.

## Open locally

Open index.html in any modern browser. No installation, build step or external dependencies are required.

## Publish with GitHub Pages

1. Create a public GitHub repository, for example night-city-map.
2. Upload index.html, .nojekyll and this README.md to its root, on the main branch.
3. In Settings > Pages, choose Deploy from a branch, then main and /(root), and Save.
4. Open the website URL shown on the Pages settings page once deployment finishes.

Upload the contents of this folder, rather than the folder itself. The HTML already contains the SVG, styles and scripts. The original Inkscape SVG and the local Sites configuration are not required for hosting.

To update the map, replace index.html with the regenerated HTML export.
